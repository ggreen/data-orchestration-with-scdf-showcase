Apache Iceberg S3 Sink

Spring Cloud Stream consumer consuming events into Iceberg tables on S3.

Configuration Overview

The application is configured using Spring Cloud Stream with RabbitMQ as the message broker. Below is an overview of the key configuration blocks defined in application.yml:

1. Server & Spring Boot Settings

  • server.port: Application port (Default: 9090).
  • spring.application.name: Sets service name (iceberg-s3-sink).

2. RabbitMQ Connection

Uses environment variables for credentials to allow secure deployment via Tanzu / Kubernetes:

  • spring.rabbitmq.username: Set via ${TANZU_RABBITMQ_USER}
  • spring.rabbitmq.password: Set via ${TANZU_RABBITMQ_PASSWORD}
  • spring.rabbitmq.virtual-host: Configured to /

3. Spring Cloud Stream Functions

Maps the functional consumer bean to streaming channels:

  • spring.cloud.function.definition: Identifies iceBergConsumer as the target functional bean.
  • bindings.iceBergConsumer-in-0: Inbound message channel mapped to standard input destination.

4. Iceberg Schema Properties

Defines the destination table details and dataset schema mapping:

Property Value in Example Description
iceberg.schemas.table-name customers Target Iceberg table name on S3.
iceberg.schemas.namespace.name default_db Target database / namespace.
iceberg.schemas.fields Array of fields Defines field IDs, names, data types, and nullability flags.

Example application.yml Reference

server:
  port: 9090
spring:
  application:
    name: iceberg-s3-sink
  rabbitmq:
    username: ${TANZU_RABBITMQ_USER}
    password: ${TANZU_RABBITMQ_PASSWORD}
  virtual-host: /  # Optional (defaults to /)
  cloud:
    function:
      definition: iceBergConsumer
    stream:
      function:
        bindings:
          iceBergConsumer-in-0: input
          iceBergConsumer-out-0: output
      binder:
        connection-name-prefix: ${spring.application.name}
iceberg:
  schemas:
    table-name: "customers"
    namespace:
      name: "default_db"
    fields:
      - id: 1
        name: "id"
        type: "integer"
        required: true
      - id: 2
        name: "name"
        type: "string"
        required: true
      - id: 3
        name: "email"
        type: "string"
        required: false
